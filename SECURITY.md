# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's
private vulnerability reporting flow when available, or contact the
maintainer privately through GitHub with a redacted reproduction, impact, and
mitigation.

Do not submit API keys, credentials, personal data, or other sensitive values.
Rotate any credential that may have been exposed during testing.

## Scope

This is a browser-based prototype. Verify calculations, privacy assumptions,
and third-party integration behavior independently before using it for
operational or regulatory decisions.
